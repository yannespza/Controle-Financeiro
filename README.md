# Meu Controle Financeiro

App de controle de gastos para o celular: contas, saldos, categorias, gráficos do mês e backup.

**Abrir o app:** https://yannespza.github.io/controle-financeiro/

- Os dados ficam guardados só no aparelho e no navegador de quem usa. Nada vai para a nuvem e ninguém mais vê.
- Dá para instalar na tela inicial: no iPhone, Safari → Compartilhar → Adicionar à Tela de Início; no Android, Chrome → ⋮ → Instalar app.
- Faça uma cópia de segurança de vez em quando na aba **Backup**.
